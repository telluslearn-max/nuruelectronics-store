## Design Philosophy

Apple simplicity. Nike confidence. Nothing editorial. Muji restraint. Monocle sophistication.

NURU should never look like a typical electronics retailer. It should feel like a premium technology publication that happens to sell electronics.

## 2. Design Principles

Every design must follow these principles.

**Less is More**
If something can be removed, remove it. Whitespace is a design element.

**Product First**
The product is always the hero. Not gradients. Not effects. Not graphics. Not icons.

**Typography Before Graphics**
Typography should carry the design. Not decorative shapes.

**Editorial Layout**
Design should resemble Apple keynote slides, magazine covers, fashion campaigns, architecture books — NOT electronics supermarket flyers.

## 4. Typography

One typeface. One family.

No script fonts. No handwritten fonts. No condensed fonts. No futuristic fonts.

**Recommended:** Helvetica Now, Neue Haas Grotesk, SF Pro Display, Inter, Suisse Int'l

### Font Stack

```css
--font-heading: 'Inter', 'SF Pro Display', 'Helvetica Now', system-ui, sans-serif;
--font-body: 'Inter', 'SF Pro Display', 'Helvetica Now', system-ui, sans-serif;
```

### Type Scale

| Element | Size | Weight |
|---------|------|--------|
| Display | 120–220pt | Bold |
| Headline | 60–120pt | Bold |
| Subheading | 28–40pt | Medium |
| Body | 18–24pt | Regular |
| Caption | 12–16pt | Regular |

---

## 5. Grid System

Use a 12-column grid.

**Margins:** 80–120px. Never place content against edges. Whitespace is mandatory.

---

## 6. Photography

Photography should feel premium.

**Only use:** official product images, or high-quality renders.

**Never use:** stock hands, random lifestyle photos, clipart, cheap mockups, low-resolution assets.

---

## 7. Shadows

Soft only. Very subtle. No glow. No dramatic drop shadows. No bevel. No emboss.

---

## 8. Icons

Use one icon family only. Outlined. 2px stroke. Rounded corners. No mixed icon styles.

---

## 9. Buttons

Rounded pills. Never rectangles.

Examples: "Shop Now →", "Learn More →", "Available Today →"

---

## 10. Brand Elements

Only recurring elements:

- NURU logo
- Small red square
- Editorial arrow →
- Website

Nothing else.

---

## 11. Spacing

Lots. More than feels comfortable. Double the whitespace. Then double it again.

---

## 12. Corners

Rounded. Consistent. Products float. No harsh boxes.

---

## 13. Copywriting

Confident. Short. Never shout.

### Prohibited Phrases

| Avoid | Reason |
|-------|--------|
| BUY NOW!! | Shouts, discount-retailer tone |
| SUPER DEAL!! | Salesy, off-brand |
| LIMITED OFFER!! | Manufactured urgency |
| Best Price!!! | Price-led, not product-led |

**Bad:**
- BUY NOW!!
- SUPER DEAL!!
- LIMITED OFFER!!
- Best Price!!!

**Good:**
- Designed to perform.
- Now available.
- Built for more.
- One device. Unlimited possibilities.
- Play this month.
- Ready when you are.

---

## 14. Price Formatting

**Never:** KES165000

**Always:** From — KSh 165,000

Price should never be the biggest element. The product always wins.

## 15. Website

Always `nuruelectronics.com`. Bottom. Small. Never dominant.

## 16. Category Systems

Every category has its own personality while remaining unmistakably NURU.

**Phones** — Cream background. Large hero phone. Massive typography. Minimal specs. Editorial.

**Laptops** — Lots of whitespace. Open laptop. One floating angle. Professional.

**Gaming** — Dark charcoal. Blue accents. Huge game artwork. Editorial typography. No clutter.

**Accessories** — Even more minimal. Accessory centred. Tiny feature list.

**Audio** — Soft shadows. Floating products. Premium.

**Smart Home** — Lifestyle-inspired. Lots of breathing room.

## 22. The NURU Rule

Before exporting, ask: "Could Apple post this?"

If yes — good. Then ask: "Does it still feel like NURU?"

If yes — export. If not — remove more.

---

## 23. The Golden Ratio (The 70/20/10 Rule)

Every NURU poster should roughly follow this visual balance:

- 70% whitespace and breathing room
- 20% product imagery
- 10% text, branding and CTAs

This is what creates the premium, calm aesthetic. Most electronics retailers reverse this ratio, filling every inch with offers and specifications.

---

## 24. The NURU Quality Checklist

Before publishing any design, score it out of 10 on these criteria:

| Principle | Target |
|-----------|--------|
| Product is the hero | ✓ |
| Typography is clean and consistent | ✓ |
| Plenty of whitespace | ✓ |
| Colour palette follows brand | ✓ |
| Copy is concise | ✓ |
| No unnecessary elements | ✓ |
| Looks premium at first glance | ✓ |
| Readable in under 3 seconds | ✓ |
| Consistent with previous NURU posts | ✓ |
| Worth saving or sharing | ✓ |

Only publish designs that score 9/10 or higher.

## AI Image Generation

### Base Prompt Template

Always prepend to image generation prompts:

```
Premium editorial product photography in the NURU style: warm white (#F8F6F2) or dark charcoal (#0F1012) background, single hero product floating with soft subtle shadow, massive whitespace (70% of frame), minimal typography, no gradients, no clutter, no stock photography, shot like an Apple keynote slide or a Monocle magazine spread.
```

### Style Keywords

| Category | Keywords |
|----------|----------|
| **Lighting** | soft, natural, even, no harsh highlights |
| **Mood** | calm, premium, confident, restrained |
| **Composition** | centered, one hero product, massive negative space, 12-column editorial grid |
| **Treatment** | soft subtle shadow only, no glow, no bevel, no emboss |
| **Aesthetic** | Apple keynote, magazine cover, fashion campaign, architecture book |

### Visual Mood Descriptors

- Quiet confidence, never shouting
- Collectible, save-worthy, editorial
- Product floats — it never sits in a busy scene

### Visual Don'ts

| Avoid | Reason |
|-------|--------|
| Stock hands or lifestyle photos | Cheapens the premium feel |
| Clipart or cheap mockups | Off-brand, low-quality |
| Low-resolution assets | Breaks the premium standard |
| Gradients, glow, drop shadows, bevel, emboss | Only soft, subtle shadows are allowed |
| Rectangular buttons or hard-edged boxes | NURU uses rounded pills and rounded corners only |
| More than one hero product, headline, and CTA | Every poster is 1 hero, 1 headline, 1 CTA |

### Example Prompts

**Hero Banner:**
```
A single smartphone floating at a slight angle against a warm white (#F8F6F2) background, soft subtle shadow beneath it, massive whitespace surrounding the product, one bold headline in Inter/Helvetica Now above it ("Designed to perform."), a small red square (#D94B32) accent mark, rounded pill CTA button reading "Shop Now →" bottom center, NURU logo small at the bottom. Editorial, Apple-keynote style, no clutter.
```

**Social Media Post (Gaming category):**
```
Dark charcoal background (#0F1012), huge game artwork centered, Gaming Blue (#0038A8) accent line, bold editorial headline, no icons, no clutter, generous margins (80-120px), rounded corners on all imagery, one small CTA pill at the bottom.
```
